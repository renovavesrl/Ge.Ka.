Guida all'uso
COME FUNZIONA IL GESTIONALE E COME COLLEGARLO A GITHUB
Panoramica
Cos'è e come funziona
Questo gestionale, Ge.Ka., è un'unica pagina web (un file .html) che gira interamente nel tuo browser: non serve installare nulla e non c'è un server. Tutti i dati del progetto (fasi, preventivi, risorse, verbali, checklist, ecc.) vengono salvati automaticamente nella memoria locale del browser (localStorage) quando premi Salva in alto a destra.
💡
Un file, un browser. Se apri il file su un altro computer, o cancelli i dati del browser, i progetti salvati "solo in locale" non sono più visibili. Per portarti i progetti dietro tra più dispositivi (PC ufficio, PC cantiere, tablet...) usa la sincronizzazione con GitHub Gist, spiegata più sotto.
Sezioni del programma
Cosa trovi in ogni voce di menu
ProgettoAnagrafica del cantiere: nome, codice, committente, data inizio e durata prevista in settimane. È il punto di partenza da compilare per ogni nuovo progetto.
Fasi & AttivitàElenco delle fasi di lavorazione (scavi, fondazioni, strutture, ecc.) con date di inizio/fine e stato di avanzamento. Da qui nasce il diagramma di Gantt.
PreventiviVoci di costo previste ed effettive, per tenere sotto controllo il budget del cantiere rispetto al preventivato.
RisorseSquadre, mezzi e fornitori impiegati nel cantiere, con relativa disponibilità nel tempo.
GanttVista grafica del cronoprogramma, generata automaticamente dalle fasi inserite.
AvanzamentoConfronto tra avanzamento previsto ed effettivo, per capire a colpo d'occhio se il cantiere è in linea con i tempi.
Verbali · Problematiche · Documenti · ChecklistSezioni documentali: verbali di sopralluogo e riunione (scheda guidata, foto scattate dal telefono, PDF e invio ai destinatari), non conformità/problemi aperti, documenti/allegati e liste di controllo (es. sicurezza, collaudi).
Sincronizzazione multi-dispositivo
Come collegare il programma a GitHub
La sincronizzazione con GitHub Gist permette di salvare i tuoi progetti su un file privato del tuo account GitHub, così puoi aprirli da qualsiasi computer o dispositivo semplicemente usando lo stesso "token" di accesso — senza bisogno di email, chiavette USB o cloud a pagamento.
1
Crea un account GitHub (se non l'hai già)
Vai su github.com/join e registrati gratuitamente. Se hai già un account GitHub, salta questo passaggio.
2
Genera un Personal Access Token con permesso "gist"
Nel programma clicca su GitHub Gist in fondo al menu laterale (oppure vai su github.com/settings/tokens/new). Assicurati che sia selezionato solo lo scope gist (non serve nient'altro). Dai una scadenza a piacere (es. "No expiration" o "90 giorni") e clicca Generate token in fondo alla pagina.
3
Copia il token e incollalo nel programma
GitHub mostra il token una sola volta (una stringa che inizia con ghp_): copialo subito. Torna nel gestionale, apri GitHub Gist nel menu laterale, incolla il token nel campo dedicato e clicca Salva.
4
Il programma crea automaticamente un Gist privato
Da questo momento, ogni volta che premi Salva, il progetto viene scritto sia in locale nel browser sia in un Gist privato collegato al tuo account (visibile solo a te, mai pubblico). Non devi fare nient'altro: la sincronizzazione è automatica.
5
Apri lo stesso progetto da un altro dispositivo
Apri il file HTML del gestionale sull'altro computer/tablet, vai su GitHub Gist nel menu, incolla lo stesso token creato al passo 2 e salva. Poi usa Apri progetto nel menu laterale: vedrai l'elenco dei progetti salvati sul Gist e potrai caricare quello che ti serve.
🔒
Sicurezza del token. Il token viene salvato solo nella memoria locale del browser che stai usando (mai inviato altrove se non a GitHub stesso) e funziona come una password: chi lo possiede può leggere/scrivere i tuoi Gist. Non condividerlo e, se pensi sia stato esposto, revocalo da github.com/settings/tokens e generane uno nuovo.
Domande frequenti
FAQ
Devo per forza usare GitHub?
No. Senza token configurato il programma funziona comunque e salva tutto in locale nel browser con Salva. GitHub Gist serve solo se vuoi accedere agli stessi progetti da più dispositivi o vuoi un backup fuori dal browser.
Cos'è esattamente un "Gist"?
Un Gist è un piccolo file di testo ospitato gratuitamente sui server di GitHub, collegato al tuo account. Il programma lo usa come un "contenitore" dove salva i dati dei tuoi progetti in formato testuale. Può essere pubblico o privato: il gestionale crea sempre un Gist privato, visibile solo a chi accede con il tuo token.
Posso usare lo stesso token su più computer contemporaneamente?
Sì. Il token identifica il tuo account GitHub, non un singolo dispositivo. Configuralo su ogni computer/tablet da cui vuoi lavorare: tutti punteranno allo stesso Gist e vedranno gli stessi progetti salvati.
Cosa succede se due persone modificano lo stesso progetto insieme?
L'ultimo salvataggio sovrascrive il precedente sul Gist: non c'è un merge automatico delle modifiche. Se lavorate in più persone sullo stesso progetto, meglio coordinarsi ed evitare di salvare nello stesso momento.
Il mio token non funziona più / ho un errore di autenticazione
Il token potrebbe essere scaduto o essere stato revocato. Genera un nuovo token da github.com/settings/tokens con scope gist e reinseriscilo nel programma tramite GitHub Gist nel menu laterale.
Come faccio un backup dei dati?
Se hai configurato GitHub Gist, il tuo Gist privato è già un backup accessibile da github.com con il tuo account. Puoi inoltre usare Esporta PDF in alto per salvare un'istantanea stampabile del progetto in qualsiasi momento.
I miei dati vengono inviati a server diversi da GitHub?
No. Il programma comunica solo con le API ufficiali di GitHub (api.github.com) per leggere/scrivere il Gist. Non ci sono altri server o servizi terzi coinvolti nel salvataggio dei dati.
